# 💫 About Me:
# ¡Hola, soy Yussef! 👋

**Desarrollador Full Stack** con gran autonomía y curiosidad, enfocado en la creación de aplicaciones web escalables y la automatización de procesos. Combino mi experiencia operativa en IT con sólidos conocimientos en programación para construir soluciones eficientes que resuelven problemas reales de negocio. Disfruto el proceso completo: desde la estructuración de la base de datos hasta el despliegue de una interfaz fluida e intuitiva.

A través de mis proyectos y mi experiencia profesional, he perfeccionado mis habilidades técnicas desarrollando soluciones como:

- 📦 **[Inventory Pro](https://github.com/Annorakx/Inventory-Pro):** Sistema full-stack de gestión de inventario basado en una arquitectura Cliente-Servidor (React, Python, REST APIs). Permite la administración en tiempo real de productos, facturación y control de stock, optimizando los flujos de trabajo operativos.
- 💰 **[Gastos App](https://github.com/Annorakx/Gastos-App):** Aplicación web moderna para la gestión de finanzas personales utilizando tecnologías de vanguardia como React + Vite, Tailwind CSS y Supabase. Enfocada en el rendimiento, la visualización de balances en tiempo real y la privacidad del usuario.

Actualmente busco nuevos desafíos donde pueda aportar mi entusiasmo y mis habilidades técnicas para construir productos digitales robustos en un entorno colaborativo.
